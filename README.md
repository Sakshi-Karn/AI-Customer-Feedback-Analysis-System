# AI-Based Customer Feedback Analysis System Using Sentiment Analysis

## Overview
This project is a MERN Stack based web application that analyzes customer feedback using AI-powered sentiment analysis.

The system classifies feedback into:
- Positive
- Negative
- Neutral

It also provides dashboard analytics and graphical sentiment visualization.

---

## Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Chart.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI/NLP
- Sentiment Analysis
- Hugging Face API
- NLP techniques

---

## Features
- User Authentication
- JWT Login System
- Feedback Submission
- AI Sentiment Detection
- Analytics Dashboard
- Dark Mode UI
- Graphical Reports
- MongoDB Integration
